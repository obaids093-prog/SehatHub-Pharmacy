To download any youtube video with the help of python:

Step 1: Install this library first

pip install yt-dlp 

Step 2: Install ffmpeg (Fast forward moving picture experts group) 

winget install Gyan.FFmpeg.Shared

At the end, after install just press Y to done it. 

Step 3: Run this code 

import yt_dlp

url = input("Youtube URL: ")

yt_dlp.YoutubeDL(
    {"format" : "bestvideo + bestaudio"}
).download([url])

Step 4: Put your URL below of specefic youtube video.
